01

Single Side Clothes單邊服裝

v1.4.0
KK · KKSMaker 創角CharaStudioMain game 本篇

Show only the left or right piece of gloves, pantyhose, legwear, shoes and paired accessories. Set per outfit, saved in the character card.

手套、褲襪、襪子、鞋子與成對配件可以只顯示左邊或右邊，
依服裝設定並存進人物卡。

  • Both / Left / Right switch in the clothing tabs and accessory window創角服裝分頁與配件視窗的「雙邊／左／右」切換
  • Works with ClothesToAccessories and paired Arm / Leg accessories支援 ClothesToAccessories 服裝配件與手臂／腳成對配件
  • Game and mod files are never modified不修改任何遊戲檔與模組檔
Sharing cards? The other person needs this plugin too, or both sides are shown. 分享人物卡時，對方也要安裝本插件，否則會顯示左右兩邊。

Based on an idea by Nil (KK_SingleShoe) · 構想來自 Nil 的 KK_SingleShoe

Pseudo Maker Extras

v1.3.0 beta
KK · KKSCharaStudioTesters wanted · 徵求測試

Adds maker settings that Studio Pseudo Maker lacks, so you can edit characters right in a scene.

在 Studio Pseudo Maker 補上創角才有的設定，直接在場景裡調整角色。

  • ABMX bone sliders with Split XYZ and Side to editABMX 骨骼滑桿，可分開 XYZ、左右分別調整
  • Accessory Move button next to Copy配件 Transfer 分頁的 Move 按鈕
  • Fang switch + EditFangs length / spacing sliders八重齒開關與 EditFangs 長度／間距滑桿
  • Single Side Clothes switches · ClothingBlendShape sliders with Timeline單邊服裝開關 · ClothingBlendShape 滑桿（支援 Timeline）

Shader Swapper Null Fix

v1.0.0
Optional fix · 選用修正KK · KKSMaker · Studio · Game

Stops Shader Swapper from wiping an outfit's Material Editor textures after an accessory transfer.

避免 Shader Swapper 在配件轉移後，讓整套服裝的 Material Editor 貼圖消失。

  • Skips Shader Swapper's hook only for objects that don't exist yet只在物件尚未建立時跳過 Shader Swapper 的攔截
  • Everything else Shader Swapper does is unchangedShader Swapper 其他功能完全不變

Only needed if you run into this problem · 遇到這個問題時才需要

KKUTS Clothes Redirect

v1.0.0 / v1.1.0
Optional fix · 選用修正KKS + KK (KKUTSclothes Compat)Needs Material Editor

KKUTS outfits look the same after moving between KK and KKS, without editing cards.

使用 KKUTS 的服裝在 KK 與 KKS 之間搬移後外觀一致，不修改卡片。

  • KKS: KKUTS → KKUTSclothes on everything except the bodyKKS：身體以外改用服裝用的 KKUTSclothes
  • KK: KKS-only KKUTSclothes → KKUTS when loading KKS cardsKK：讀取 KKS 卡片時把 KKUTSclothes 換回 KKUTS

Only useful when moving KKUTS outfits between games · 在兩個遊戲間搬移 KKUTS 服裝時才用得到

StripTease2 Timeline

v0.5.0 experimental
Experimental · unofficial · 實驗性・非官方KK · KKSCharaStudioNeeds StripTease2 (ziglo) + Timeline

Animate StripTease2 garment deformations in Timeline.

讓 StripTease2 的服裝變形可以在 Timeline 裡做動畫。

Stopgap only. ziglo has announced official Timeline support in a future StripTease2 version. Switch to it and remove this plugin once it is out. 僅供實驗性使用。原作者 ziglo 已宣布未來的 StripTease2 會正式支援 Timeline，推出後請改用官方版本並移除本插件。
  • Strip progress 0–100 per clothing slot各部位的脫衣進度 0–100
  • Body mask Top / Bottom switched on keyframes上身／下身身體遮罩依關鍵影格切換
  • Drop: garment falls to the ground (simple fall, not physics)Drop：服裝掉落到地面（簡單掉落，非物理模擬）
  • Keeps edit sessions when switching garments · fixes vanishing garments切換服裝時保留編輯狀態・修正服裝在某些角度消失
