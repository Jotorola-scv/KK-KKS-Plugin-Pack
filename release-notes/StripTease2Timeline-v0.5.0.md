A CharaStudio companion plugin that animates **StripTease2** garment deformations with **Timeline**.

**Download**
- Koikatsu / Koikatsu Party: `KK_StripTease2Timeline.dll`
- Koikatsu Sunshine: `KKS_StripTease2Timeline.dll`

Put the dll in `BepInEx/plugins`. Requires StripTease2 (ziglo) and Timeline. Checked against StripTease2 1.3.0 and 1.4.1.

**What's in it** (Timeline > StripTease2, values set in the Shift+F10 window)
- *Strip progress* 0–100 per clothing slot (original shape ↔ StripTease2 result)
- *Body mask* Top / Bottom, switched exactly on keyframes
- *Drop*: the garment falls to the ground (a simple deterministic fall, not cloth physics)
- Settings: keep edit sessions when switching garments, fix garments vanishing at some camera angles

See the [README](https://github.com/Jotorola-scv/KK-KKS-Plugin-Pack/tree/main/StripTease2Timeline) for details and limitations.
